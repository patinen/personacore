ProjectPulse documents a public-GitHub-repository engineering dashboard built with Next.js/TypeScript, NestJS/Prisma, PostgreSQL and Redis/BullMQ. The API primarily reads stored snapshots; a separate non-HTTP worker fetches GitHub observations and transactionally stores dashboard/repository snapshots. API scheduling refreshes tracked repositories every 15 minutes; queue deduplication, retries and backoff separate reads from synchronization. OAuth/discovery and the first dashboard read without a snapshot can still call GitHub. Charts use the last snapshot per UTC day, not reconstructed history; seven-day commit metrics are rolling counts, not daily totals. Missing days are not backfilled; activity is bounded/incomplete. Snapshot retention/daily rollups and webhook-triggered synchronization are future work; a queued API refresh endpoint exists but manual UI controls do not. Private repositories are unsupported. Deployment/test descriptions are repository reports, not independently validated here or personal skill evidence.
