SecureShare documents temporary text/private-file sharing through secret links with expiry/access limits; creators use GitHub login and recipients explicitly open/download. Next.js/TypeScript Web/BFF calls a private Go API backed by PostgreSQL, Redis and private R2 storage; a private worker handles cleanup. Capability tokens are stored as hashes; GET does not consume access and atomic PostgreSQL POST redemption arbitrates one-time races. Files use a PENDING → READY → PURGED lifecycle with shared private upload spool and reconciliation across storage/database failures. Short-lived signed attachment URLs remain reusable until expiry; revocation cannot cancel issued URLs/transfers. It is not E2EE and has no malware scanning. The README lists further cleanup, recovery and operational privacy checks as pending; documentation-reported deployment/test results are not independently verified here.
